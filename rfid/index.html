接線與第一次測試

RC522：3.3V → 3V3、GND → GND、SDA/SS → GPIO5、SCK → GPIO18、MOSI → GPIO23、MISO → GPIO19、RST → GPIO27；IRQ 不接。

繼電器訊號腳為 GPIO26。先保持 RELAY_ENABLED=false，完成讀卡、登錄與借還測試，再依模組和電鎖額定電壓接線並啟用輸出。合法使用者卡解鎖 5 秒，物品卡完成借還登記。

卡片命名在 USB 序列監控完成：例如 {"cmd":"user","uid":"實際卡號","name":"小明","quota":3}。每件物品另用一張卡，UID 不可重複。
