隱私權政策

這份政策說明「歌詞島」iOS App 與本網站如何使用資料。

生效與更新日期：2026 年 10 月 11 日 · 適用版本：歌詞島 1.0.10

1. 開發者與聯絡方式

歌詞島由 panda-island 開發與維護。如有隱私或資料處理問題，請透過使用支援頁的聯絡管道提出。GitHub 回報內容為公開資訊，請勿在公開回報中提交密碼、權杖或其他敏感資料。

2. 我們使用哪些資料

歌詞島沒有自建的使用者帳號系統，也沒有開發者營運的資料收集伺服器。App 不包含廣告 SDK 或第三方分析 SDK。提供功能時仍會處理以下資料：

資料用途處理位置
正在播放的歌名、演出者、專輯、長度、播放時間及播放狀態找出歌曲並對齊歌詞；在 App 與即時動態中顯示資訊。裝置上處理；從系統 Music 播放器取得。
歌名、演出者、專輯與歌曲長度向 LRCLIB、網易雲音樂、QQ 音樂、酷狗音樂與 AMLL 社群歌詞庫尋找對應的時間軸歌詞。透過 HTTPS 傳送到上述來源。
匯入的 LRC 文字與每首歌曲的歌詞延遲提供使用者選擇的歌詞及同步偏好。保存在裝置上的 App 儲存空間，不由 App 上傳至開發者伺服器。
使用者主動提交的支援內容回答問題、調查錯誤或處理建議。經 GitHub 問題回報管道提交，回報內容會公開。
背景更新時間、背景方式與中斷摘要協助判斷同步是否停止或程式是否重新啟動。僅在裝置保留最新心跳快照，不上傳。

3. 權限與第三方服務

Apple Music：App 只會在你允許「媒體與 Apple Music」存取後，讀取系統 Music 播放器提供的音樂資訊。你可以在 iOS 設定撤銷權限。

歌詞來源：自動查詢歌詞優先使用 LRCLIB，沒有同步歌詞或查詢失敗時再使用網易雲音樂、QQ 音樂、酷狗音樂及 AMLL 社群歌詞庫。查詢會傳送比對所需的歌曲資訊；簡轉繁在裝置上完成，不上傳到翻譯服務。LRCLIB、網易雲音樂、QQ 音樂、酷狗音樂、AMLL 及 GitHub 等服務在接收網路請求時，也可能依各自政策處理 IP 位址、請求時間及技術紀錄；開發者不控制第三方的資料保留方式。

  • Apple 隱私權政策
  • LRCLIB 服務網站
  • GitHub 隱私權聲明

4. 保存與安全

無聲音訊在裝置上產生並播放，不使用麥克風、不錄音，也不傳送音訊到伺服器。

各歌詞來源的網路請求使用 HTTPS。匯入的 LRC、背景與顯示偏好及歌詞延遲保存在 App 的本機儲存空間；查詢到的歌詞也可能由 App 或系統暫存。開發者不另行保存你的聆聽紀錄。

即時動態可能在鎖定畫面顯示歌名與歌詞，裝置旁的其他人可能看見。你可以停止同步或在 iOS 設定關閉即時動態。

5. 移除資料與撤銷授權

  • 1.0.9 已移除 Spotify 支援，升級會清除可存取的舊 Spotify 權杖與 Client ID。服務端授權可在 Spotify 帳號應用程式管理中撤銷。
  • 在 iOS 隱私設定中撤銷「媒體與 Apple Music」存取，可停止 App 讀取該服務的音樂資訊。
  • 刪除 App 可移除其本機設定與匯入 LRC。
  • 如希望修改或移除你主動提交的支援內容，請透過支援管道聯絡；公開 GitHub 內容及第三方紀錄另受 GitHub 的管理方式約束。

資料存於第三方服務時，相關存取、刪除或其他資料請求，請依該服務的官方管道辦理。

6. 本網站

本網站由 GitHub Pages 提供託管。本網站本身沒有登入、廣告、追蹤分析程式、表單或自行設定的 Cookie；圖片與樣式由同一網站提供。GitHub 可能為託管、安全與服務營運處理技術資訊，詳見其隱私權聲明。點擊外部連結後，資料處理由該網站的政策規範。

7. 政策更新

若 App 的功能或資料處理方式變更，會更新本頁及上述日期。新版本涉及不同的權限或第三方服務時，會依實際功能調整說明。
