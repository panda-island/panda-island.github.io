從連接音樂，到找到剛剛好的歌詞時間。

聯絡歌詞島

開發與維護：panda-island。你可以透過公開的 GitHub 問題回報頁提出使用問題、錯誤回報或功能建議；需要 GitHub 帳號。

提交問題回報 ↗

回報內容會公開。請只提供 App 版本、iOS 版本、機型與操作步驟，不要填入密碼、授權權杖或私人歌詞檔案。

Apple Music 設定

  1. 先在 iPhone 的 Music App 播放歌曲。
  2. 開啟歌詞島，選擇 Apple Music 並點「開始同步」。
  3. 依提示允許「媒體與 Apple Music」存取。
  4. 若沒有歌曲資訊，確認 Music App 正在播放；部分雲端或非資料庫歌曲可能無法提供資訊。

Spotify 設定

目前版本使用你自己的 Spotify Developer Client ID 連接帳號。

  1. 在 Spotify Developer Dashboard 建立 App，登記 Redirect URI：lyrics-island://spotify-callback。
  2. 開啟歌詞島設定，填入該 App 的 Client ID，點「連接 Spotify」。不要填 Client Secret。
  3. 完成 Spotify 授權。開發模式需符合 Spotify 的帳號及允許使用者規則。
  4. 在 Spotify 播放音樂，再回到歌詞島選擇 Spotify 並開始同步。

常見問題

為什麼離開 App 後歌詞停止更新？

iOS 26 可選系統背景會話，以真實播放校正回報進度，系統可提前結束或由使用者取消；進度介面也可能影響動態島排列。舊 PiP 方式保留，但可能遮住動態島。若 PiP 未啟用或中斷，App 主要在前景讀取播放資訊。音樂在其他 App 播放，並不會讓歌詞島取得持續背景執行時間；離開前景後只利用系統允許的短暫時間完成更新，時間結束會顯示「同步暫停」，回到 App 即可恢復。本版不使用無聲音訊維持背景，無法保證長時間持續同步。

動態島可以一直跑馬燈嗎？

目前動態島以逐句切換顯示歌詞。iOS 控制即時動態的更新及動畫，無法可靠提供持續的自訂跑馬燈。連續跑馬燈位於歌詞島 App 內。

找不到歌詞或版本不對，怎麼辦？

App 會查詢 LRCLIB，必要時備援網易雲音樂、QQ 音樂、酷狗音樂及 AMLL 社群歌詞庫。各來源不一定有對應版本的時間軸歌詞，也可能暫時無法使用。請在該曲播放時，匯入你有權使用的 UTF-8 LRC 檔案；檔案須包含如 [00:12.50] 的時間標記。你也可以使用「重試歌詞」重新搜尋。

歌詞比音樂早或晚出現？

使用歌詞延遲滑桿。歌詞太早時增加正值；歌詞太晚時使用負值。範圍為 −10 至 +10 秒，每 0.1 秒一步，設定依歌曲保存。

沒有動態島，仍然能使用嗎？

可以。歌詞島需要 iOS 17 或以上；動態島只會出現在支援它的 iPhone。其他機型可使用 App 內歌詞與鎖定畫面即時動態。也請確認 iOS 允許歌詞島顯示即時動態。

Spotify 讀取失敗或顯示請求過於頻繁？

請確認 Client ID、Redirect URI、授權與開發模式允許使用者設定。若顯示等待秒數，等待後再開始同步；必要時重新登入。播客、廣告及沒有歌曲資料的播放項目不會提供歌曲歌詞。

如何中止授權或移除本機資料？

在歌詞島設定中登出 Spotify，可刪除本機 Spotify 權杖；也可在 Spotify 帳號的應用程式設定撤銷存取。Apple Music 權限可在 iOS 隱私設定中撤銷。刪除 App 會移除其本機設定與匯入的 LRC；鑰匙圈權杖可能保留，建議先登出再刪除。

目前可以從 App Store 下載嗎？

歌詞島目前尚未在 App Store 上架。此網站提供產品介紹、使用支援與隱私權政策；正式上架後會更新下載資訊。
